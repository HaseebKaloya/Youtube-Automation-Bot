## 📖 Overview

**KaloyaXploit YouTube Automation Bot** is a professional-grade application that provides both GUI and CLI interfaces for legitimate YouTube channel management. Built with modern Python, it helps content creators and marketers automate engagement while maintaining compliance with YouTube's policies.

> ⚠️ **Important Notice**: This tool is designed for managing accounts you own. Always respect YouTube's Terms of Service and use responsibly.

## 🚀 Features

### 🎯 Dual Interface Support
- **🎨 GUI Version**: Modern desktop application with CustomTkinter
- **🖥️ CLI Version**: Command-line interface for advanced users and scripting
- **🔄 Shared Core**: Both versions use the same robust automation engine

### 🤖 Automation Capabilities
- **💖 Smart Liking**: Auto-like videos from predefined lists
- **💬 Intelligent Commenting**: Post contextual comments with templates
- **📢 Targeted Subscriptions**: Subscribe to relevant channels
- **🔄 Process Tracking**: Avoid duplicates with persistent state management

### 🎨 Professional GUI Features
- **🌙 Dark Theme**: Modern, eye-friendly interface
- **📊 Real-time Analytics**: Live statistics and progress tracking
- **📝 Enhanced Logging**: Color-coded, emoji-rich activity logs
- **⚙️ Centralized Controls**: Intuitive dashboard for all operations

### 🔧 Advanced Technical Features
- **🛡️ Exponential Backoff**: Intelligent retry mechanism for API limits
- **🔐 Secure Authentication**: OAuth 2.0 with token management
- **💾 State Persistence**: Resume operations after interruptions
- **📈 Progress Tracking**: Real-time progress bars and status updates
